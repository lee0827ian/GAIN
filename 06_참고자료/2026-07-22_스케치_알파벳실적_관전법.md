- 장기차입 $465억(25말) → $775억(1Q말)

- **"주가가 캐펙스의 제약조건이 됐다"**: 재원이 영업현금흐름 → 주식 발행으로 이동. 주가 하락 = 같은 $400억 조달에 더 많은 희석 = CAPEX 여력 실압박. **"하이퍼스케일러 캐펙스 무한정" 전제가 주식·채권시장 컨디션 연동으로 전환**

**⑥ 제미나이 3.5 지연·딥마인드 인재 이탈 ≠ 메모리 악재**: 모델 순위와 컴퓨트 구매는 다른 변수 — 뒤처지면 오히려 학습 컴퓨트 증액 유인. 지연의 진짜 타격은 클라우드 매출 믹스이지 CAPEX가 아님

**⑦ EPS 착시 경보**: 1Q 순익 $625.8억 중 **~$370억이 비상장 지분(앤트로픽·스페이스X) 평가익** — 제외 시 EPS 2.62 = 컨센 1센트 미스였음. 앤트로픽 밸류 재상승으로 이번 헤드라인 EPS가 컨센($2.86~2.90)의 2~3배로 찍힐 수 있음 — **"EPS 폭발" 헤드라인 새벽 오독 주의, 기타수익 라인 제외하고 볼 것**

**체크리스트 요약**: ⑴ CAPEX $1,900억 상단 재상향 여부 ⑵ 서버 60% 비중 유지 여부 ⑶ 2027 표현이 "significantly"보다 강해지는지 ⑷ "수요는 있는데 캐파가 못 따라간다" 반복 여부

## 프레임워크와의 정합성 (Claude 평가)

- **신설 가치 — "주가 = CAPEX 제약조건" (재귀성 축)**: 기존 "빅테크 CAPEX = 물리적 고정(급제동 불가)" 축의 첫 구조적 반론. 다년 프로젝트라 멈추진 못해도 **재원이 자본시장에 연동되면 주가 하락 → 조달 위축 → CAPEX 압박 → 메모리 수요 훼손의 되먹임 회로**가 생김. 이건규 "오라클도 3년치 현금"·도이체방크 "여력 충분"과 삼자 병기 — 판정: ATM 집행 속도, 빅테크 회사채 스프레드(v0.3 감시축과 접합)
- **북투빌 1.5~2배·서버 비중 60% = CAPEX 감시축의 실측 계기판**: "헤드라인 CAPEX ≠ 메모리 수요" — 전력·부지 병목(AI 물리 제약 축)이 심할수록 같은 CAPEX에서 메모리 풀스루 하락. 프레임워크에 없던 해상도
- **EPS 착시 = 새벽 헤드라인 오독 방지 장치**: 남조선 바로미터 루프(미장 서사가 국장에 몰아 반영)에서 잘못된 첫 해석이 국장 하루를 지배할 수 있음 — 7/23 아침 판독 시 기타수익 제외 필수
- 제미나이 지연 판독(컴퓨트 구매와 무관)은 K3 쇼크 논리 기각과 동형 — "모델 경쟁 심화 = 컴퓨트 수요 증가" 일관
