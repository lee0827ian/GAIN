# 참고자료 — CXMT IPO 충격 + 2030 메모리 수급 반론 (카이에 de market / zephyr_z9 / Barron's)

> 2026-07-16 수집. **오전 분석노트(한은인상_버핏경고)의 하이닉스 -10% 갭 2요인 판독을 3요인으로 수정하는 문서.**

## 1. Barron's — 급락의 실제 동인은 CXMT IPO

- **CXMT(창신메모리) 상하이 상장 27일, 예상 시총 약 130조원**. IPO 흥행 → 조달 자금으로 증설·점유율 확대 우려
- 이 경쟁 우려가 **마이크론 15일 장중 -6.5%, SK하이닉스 ADR -9.4%** 하락의 동인이라고 보도
- 단서: CXMT는 미국 대중 수출제재 대상 → **HBM 등 첨단 메모리 생산은 어려울 전망**

**판독 — 하이닉스 갭 채점 기준 수정**: 오전에는 "MU 동조(글로벌) + 한은 긴축(국내)" 2요인으로 봤으나, ADR -9.4%의 1차 동인은 CXMT였음. 즉 오늘 국장 하이닉스 -10% 갭 = ①CXMT 경쟁 우려(주동인) + ②한은 긴축 개시 + ③MU 동조. 종가 채점 시 CXMT 서사의 수명(27일 상장까지)을 별도 추적.

## 2. zephyr_z9 — CXMT 4배 증설을 다 넣어도 2030 부족률 25%

| 공급 | 3사 2배+ 증가 + 중국(CXMT 포함) 4배 증가 | **128.8** (약 4,700K/M) |
| 수요 | Agentic CPU | 75.0 |

- **공급부족률 18% → 25%로 오히려 확대**
- 보수성 주장: 피지컬 AI(휴머노이드·자율주행)향 수요는 아예 미모델링 — DC/AI 추정이 과하더라도 상쇄된다는 논리
- 교차점: ASML의 2030 DRAM 수요 전망 ~130EB(비트 CAGR 26%) — zephyr 수요 157.5EB는 ASML보다도 공격적

**판독**:
- 구조 반론의 골자 = **CXMT는 공급 변수로 이미 다 반영해도 부족이 심화** — 오전 리캡의 Omdia "HBM 하락 2030부터"와 같은 시간표
- 수요의 최대 항목이 HBM이 아니라 **Agentic CPU 75EB(수요의 48%)**인 점 주목 — 범용 서버 D램이 슈퍼사이클의 본체라는 프레임 (하이닉스·삼성 범용 D램 가격 결정력에 유리)
- 리스크 축은 둘로 분리: ①단기 = CXMT IPO 수급·심리 이벤트(27일까지), ②구조 = CXMT 기술 추격 속도(제재로 HBM 봉쇄가 현재 방어선)
- 프레임워크 L2-1 트리거④(메모리 가격 꺾임) 감시에 "중국 캐파 4배" 변수 정식 편입
