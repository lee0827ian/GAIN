# 고노고 글쓰기 — 지식베이스

> X(구 트위터) 거시경제 인플루언서 GONOGO(@GONOGO_Korea)의 글을 학습해
> 우리만의 거시→미시 톱다운 실시간 경제 측정 프레임워크를 만드는 프로젝트.
> 용도: 투자 판단 보조 + 경제 공부.

## 구조

```
00_원문/           복붙 원본 (YYYY-MM-DD_주제.md) — 수정 금지
01_분석노트/       글별 분석 (원문과 같은 파일명 1:1 매칭)
02_프레임워크.md   살아있는 판단 체계 문서 (최종 산출물)
03_용어사전.md     고노고 은어 사전
```

## 운영 흐름

1. IAN이 X에서 글 복붙 (채팅에 바로 붙이거나 00_원문에 파일로)
2. Claude가 원문 저장 → 은어 해독 → 분석노트 작성 → 프레임워크·용어사전 갱신
3. 여러 글을 몰아서 줘도 배치 단위로 동일 처리

## 규칙

- **필터**: 주식·증시·경제·정치 관련 글만 분석. 잡담·기타 글은 제외 (IAN 지시, 2026-07-16)
- **은어**: 문맥상 명확하면 "추정"으로 등록, 애매하면 반드시 IAN에게 질문 후 "확정"
- **원문 보존**: 00_원문 파일은 복붙 그대로(욕설 포함), 사후 수정 금지
- **프레임워크**: 모든 분석이 02_프레임워크.md 한 파일에 누적 반영. 뼈대(L1 거시 → L2 중간 → L3 미시)도 고노고의 사고 구조에 맞춰 계속 조정

## 2단계 (예정)

프레임워크의 "근거 지표"가 충분히 모이면 FRED 등 공개 데이터와 연결한
신호등 대시보드를 별도 설계로 진행.
