# 고노고 글쓰기 — 지식베이스

> X(구 트위터) 거시경제 인플루언서 GONOGO(@GONOGO_Korea)의 글을 학습해
> 우리만의 거시→미시 톱다운 실시간 경제 측정 프레임워크를 만드는 프로젝트.
> 용도: 투자 판단 보조 + 경제 공부. 모든 문서는 개인 공부용이며 투자 권유가 아님.

## 처음 읽는 세션을 위한 안내 (Claude 웹 포함)

이 레포의 중심 문서는 `02_프레임워크.md` 하나다. 나머지는 전부 그 문서를 만들기 위한 재료(00·01·06)이거나 그 문서를 적용한 산출물(04·07)이다.

새 세션에서 맥락을 잡는 순서:

1. `02_프레임워크.md` — 판단 체계 전체. 헤더의 버전(v0.xx)과 맨 아래 갱신 로그로 최신 상태 확인
2. `04_모의판독/` 최신 날짜 파일 — 지금 시점의 실측·플랜·시나리오
3. `03_용어사전.md` — 고노고 은어 해독 (벗어=매수, 입어=매도, 이 년=미 2년물 금리 등)
4. 특정 주제의 근거가 필요하면 `06_참고자료/` 해당 날짜 파일

## 구조

```
00_원문/           고노고 X 글 복붙 원본 (YYYY-MM-DD_주제.md) — 수정 금지
01_분석노트/       원문별 분석 (원문과 같은 파일명 1:1 매칭)
02_프레임워크.md   살아있는 판단 체계 문서 (L0 구조론 → L1 거시 → L2 중간 → L3 미시 + 사고 패턴 8칙 + 캘리브레이션) — 최종 산출물
03_용어사전.md     고노고 은어 사전 (추정/확정 구분)
04_모의판독/       프레임워크를 실전 적용한 기록 — 개장전 브리핑, 장중뷰, 실적 채점, 투자 플랜, 시나리오 플레이북
06_참고자료/       제3자 소스(X 스레드·IB 리서치·기사) 학습 배치 — 프레임워크 갱신의 근거 문서
07_습작/           고노고체 글쓰기 연습 + 일반 독자용 아티클 + SNS 포스팅본
07_습작/_스타일가이드.md   습작·아티클 검수 체크리스트 (AI 티 패턴 8종 금지)
```

## 운영 흐름

1. IAN이 X에서 글 복붙 (채팅에 바로 붙이거나 00_원문에 파일로)
2. Claude가 원문 저장 → 은어 해독 → 분석노트 작성 → 프레임워크·용어사전 갱신
3. 제3자 소스(고노고 외 계정·증권사 코멘트)는 06_참고자료에 학습 배치로 정리 후 프레임워크에 반영
4. 실적 발표·급락 같은 이벤트 날은 04_모의판독에 실측·채점 기록, 필요시 07_습작에 글로 변환
5. 여러 글을 몰아서 줘도 배치 단위로 동일 처리. 매 배치마다 git 커밋

## 문서 규칙

- **필터**: 주식·증시·경제·정치 관련 글만 분석. 잡담·기타 글은 제외 (IAN 지시, 2026-07-16)
- **은어**: 문맥상 명확하면 "추정"으로 등록, 애매하면 반드시 IAN에게 질문 후 "확정"
- **원문 보존**: 00_원문 파일은 복붙 그대로(욕설 포함), 사후 수정 금지
- **프레임워크**: 모든 분석이 02_프레임워크.md 한 파일에 누적 반영. 대체된 기록은 삭제가 아니라 축약·통합하며 쌓기 (유지 원칙, 07-23)
- **판정 기계화**: 예측 대신 판정 조건을 미리 숫자로 정해두고 가격·실적이 답하게 한다. 상반된 뷰는 양쪽 병기 후 지표로 판정 (7칙)
- **캘리브레이션**: 고노고의 오판도 기록해 맹신 방지. Claude 분석의 정정 이력도 갱신 로그에 남김
- **습작 검수**: 아티클·SNS 글은 완성 후 `07_습작/_스타일가이드.md` 체크리스트로 1회 검수 (대시·볼드·반전 프레임 등 AI 티 패턴 금지)
