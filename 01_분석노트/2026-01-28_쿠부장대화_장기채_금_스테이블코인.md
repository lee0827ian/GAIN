## 은어 해석
- **쿠부장** = 문답 형식용 가상(또는 지인) 캐릭터 — 대중 눈높이 질문자 역할
- **바나나우유 5천원→5만원** = 장기 인플레이션의 체감 비유 (화폐 실질가치 붕괴)
- **고인** = 물린 코인(죽은 코인 말장난)
- **SAYO** = "사요?"(매수하냐는 질문)
- **알빠노 시대** = 장기 계획 없는 초단기 사회 분위기
- **쿨타임** = 자금 로테이션이 한 바퀴 돌아 다시 돌아오는 주기

## 핵심 주장 — 고노고 거시관의 뼈대
1. **금 폭등·달러 약세의 근본 원인 = 장기채 신뢰 붕괴** (금본위제 회귀 아님)
   - 논리: 구조적 인플레 시대 → 30년 연 4% 이자는 실질가치 방어 불가(원금 1/10 토막) → 장기채 보유 유인 소멸 → 실물 보존 수단(금)으로 이동
   - 변곡점: 음모론 → 블랙록 등 주류 기관의 공식화 → 전 세계 컨센서스화
2. **정부의 대응 = 장기채 발행 축소 + 단기채 발행 확대** (단기채는 아직 수요 있음)
3. **단기채 쉬프트 → 스테이블코인 체제 강화**: 폭증하는 단기채 수요를 스테이블코인이 흡수 → 크립토 생태계는 구조적으로 확대 (단, 잡코인 제외 — 이더도 잡코인 취급)
4. **현재 국면 = 대혼돈 병목**: 자금이 반도체→금→에너지로 급격히 쏠림을 반복. 쿨타임 차면 회귀 — 로테이션을 사이클로 인식, 패닉 불필요

## 근거 지표
- 금 가격, 달러인덱스(DXY)
- 미 장기채 금리/수요 (10Y·30Y, 입찰 결과), 장단기 발행 비중
- 스테이블코인 시가총액 (단기채 수요 대리지표)
- 자산군별 자금 쏠림 (반도체·금·에너지 로테이션)

## 논리 구조 (거시→미시)
L1 최상단(채권시장 구조 → 금·달러·금리) → L2(자산군 로테이션, 크립토 생태계) → L3(스테이블 O, 잡코인·이더 X) — 프레임워크에서 가장 높은 층위의 글

## 프레임워크 반영
- L1에 "채권시장 구조론(장기채 붕괴 → 금 → 단기채 → 스테이블)"을 최상단 축으로 신설
