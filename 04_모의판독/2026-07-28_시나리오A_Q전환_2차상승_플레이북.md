# 모의판독 — 시나리오 A 플레이북: Q 전환 성공 → 마지막 2차 상승 (2026-07-28)

> 성격: 프레임워크 v0.24 기반 시나리오 플레이북. 예측이 아니라 **단계별 관문(gate)과 판정 조건의 기계화** — 각 관문을 실측이 통과해야 다음 단계로 진행하는 조건부 경로. 실제 주문 판단은 IAN.
> 자매 문서: 투자플랜 v1(07-24, 진입·게이트 규칙) — 본 문서는 그 위에 얹는 시간축.
> 시나리오 지위: A(본 문서) > B(계단식 하락) > C(쾅 엔딩) — 07-28 종합 판독 기준 확률 우세이나, **관문 실패 시 B/C로 즉시 분기** (§7).

## 0. 시나리오 정의와 논거

**정의**: P 사이클(가격 상승률) 변곡점을 통과한 메모리가 다운 사이클이 아니라 **Q 사이클(물량·계약)로 연착륙** → 8월 바닥 확인 → 피크아웃론 반박 촉매가 누적된 숏을 스퀴즈 → **4Q 마지막 2차 상승, ATH 재돌파** → 이후 진짜 사이클 종료. "마지막"이 전제이므로 **출구 계획(§6)이 본 문서의 최종 목적.**

**논거 4개** (전부 07-28 배치 실측):
1. **선례**: 2016-18 사이클 — ASP 증가율 둔화로 P가 끝나도 절대가격+Q 증가가 실적·주가 견인 (김두한). ASP 둔화율 = 피크아웃 공식의 직접 반박
2. **수요**: 이번 조정 중 수요 지표는 전부 상향 — MS 하이퍼스케일러 CAPEX 2027 $1.2조(+9%), 메타·TSMC·ASML 가이던스 상향, OpenAI $750B, APLD 컨센 2.7배, MS "최고 확신: 수요>공급 수년"
3. **포지셔닝**: 낙폭의 주인은 과밀 롱 청산(BofA 82% 최혼잡)이었고, 이제 버리 필두 숏이 쌓이기 시작 — **스퀴즈 연료 축적 개시**
4. **Q 재료**: LTA 확산(머스크 다년·인텔 CPU)·SOCAMM/LPDDR6(신규 응용처)·9월 2027 HBM 계약(2배 기대) — 단 현재는 내러티브 촉매 단계(김두한 유보)

**공인된 한계** (시나리오 성공 시에도):
- 상승 기울기·기간은 P 사이클 국면보다 완만 (2016-18 실측)
- 기대치: 저점 대비 ~100%, **고점 대비 수십%가 한계** (김두한) — "이제 와서 큰 욕심 부릴 자리 아님"
- Q 사이클 국면에선 메모리가 주도 섹터가 아닐 수 있음 — 순환매 지도(§5) 병행

**모든 시나리오의 공통 출발점. 여기서 갈린다.**

**Phase 0 종합 판정 (v1.1 개정 — §7과 정합화, 카운팅 룰 폐지)**:
- **필수 2관문**: 하이닉스 P·Q + MS·메타 CAPEX — **둘 다 통과해야 Phase 1 진행**. 둘 중 하나라도 실패 = A 보류·B/C 감시 모드 (§7과 동일 로직)
- **거부권 1관문**: FOMC 실제 인상 = 다른 관문 결과와 무관하게 **즉시 A 중지**
- **보조 2지표**: 애플 총마진·AWS — 기록·참고만, 단독으로 판정을 바꾸지 못함

## 2. Phase 1 — 첫 반등과 되밀림 (8월 초~중순)

**성격**: 여기서의 반등은 아직 신호가 아니다 — 반등론·계단론 양 진영 공통 전제. **되밀림이 진짜 시험.**

- **데드캣 판별 3종** (김석환, 기계화):
  1. 첫 반등에 거래대금 동반 여부 — 거래대금 없는 지수 반등 = 기술적 반등 판정
  2. **되밀림에서 7/28 저점(코스피 6,073·하이닉스 157.75만 부근) 유지 여부** — 저점 안 깨지면 "중간 조정" 해석 근거 확보 = A의 첫 구조적 증거
  3. 외국인 현물 순매수 전환 여부
- **8월 3Q 고정가 발표 = P의 마지막 확인이자 Q 서사의 개시점**: 인상폭 서프라이즈(이건규 기대)면 "상승률 둔화·절대가격 상승"의 2016-18 궤도 확인. 둔화 명시면 §7 분기
- **노무라 8월 창 중첩 경계**: 실적 시즌 종료 후 변동성 쇼트 청산 리스크 — VIX 25+ 급등 시 패턴③("청산은 기회") 발동 검토 구간이자, 플랜 §4 반액 상한 규칙 적용
- 이 구간의 예상 모양: V자가 아니라 **출렁이며 바닥 다지기** (김두한·DS·노무라 3자 합의) — 저점 재테스트 1~2회는 시나리오 A 안에서 정상

**Phase 1 통과 조건**: 되밀림 저점 유지 + 3Q 고정가 인상 확인. → Phase 2.

**성격**: "P 막바지" 컨센이 "Q 연장" 컨센으로 교체되는지 — 내러티브 전쟁의 승부처.

| 확인 지표 | A 확인 | 의미 |

| **9월 2027 HBM 계약 협상** | 계약가 대폭 인상(최대 2배 기대) + 물량 락인 | LTA가 내러티브 촉매에서 **실계약으로 승격** — 시클리컬 탈출 논거의 첫 실물 |
| 2027 EPS 컨센 방향 | 상향 리비전 재개 | "2028 할인" 폐기 or 순연의 정량 증거 |
| 숏 포지셔닝 | 숏 잔고 증가 후 스퀴즈 개시 (급등일 동반 대량 환매수) | 2차 상승의 연료 점화 |

| 엔비디아 CDS·빅테크 스프레드 | 진정·횡보 | C 시나리오 소등 확인 |

**진입 규칙 (플랜 v1 연동)**: Phase 2 확인 + 게이트 🔴 1개 이하 → 분할 1/3 개시. 신규 좌표: ~~200만 문턱~~ → **170만 회복·안착(2거래일)이 1차 관문**, 200만은 저항(저씨 데드캣 상한) — 200만 돌파·안착이 2차 관문(추가 1/3). 캘리브레이션 주의: "확인 후 진입"은 심리가 아니라 조건 근거 — 확인 비용(가격)과 불확실성 베팅의 교환임을 명시.

## 4. Phase 3 — 2차 상승 (4Q, 중간선거 전후)

- 경로: 숏 스퀴즈 + Q 내러티브 안착 → **메모리 ATH 재도전** (하이닉스 기준 298.7만). 김두한: "다시 ATH를 돌파하리라 생각한다 — 단 그 이후 얼마나 더 오를지는 모른다, 오직 대응"
- **동반 랠리 폭 감시**: 이번 상승은 메모리 단독이 아니라 빅테크+타 섹터 동반이 건강 신호 (김두한 4Q 전망) — 메모리만 오르는 협소 랠리는 오히려 말기 신호
- 매크로 순풍 조건: 디스인플레 지표 재개 + 인하 사이클 접근(DS: 캐펙스 조절→달러 약세→금리 하향 경로) + 11월 정치 이벤트(희토류 유예 11/10·APEC 11/18 — 공개 대치 = 예측 가능성 상승)
- **랠리 중에도 매 분기 반복 채점**: P 상승률 / Q 실측 / 배수 반응 — 특히 "호실적+하락"이 재출현하면 §6 즉시 가동

## 5. 순환매 병행 지도 (Q 국면의 손익비 대안)

김두한 지적대로 2차 상승의 주도주가 메모리가 아닐 가능성 병기 — "메모리는 사이클이냐 구조냐 프레임에서 벗어나 넓게":

| 후보 | 조건 | 경계 |
|---|---|---|
| 바이오 | 금리인하 + P 하락 조합 시 수급 이동 | 인하 지연 시 무효 |
| 반도체 소부장 (폭락분) | Q 사이클 = 캐파 투자 수혜 | **중국 매출 비중 높은 기업 제외** (DUV 자립 뉴스) |
| SW 순환매 | SaaS 종말론 공포 완화 시 저평가 반등 | 해자 증명 종목은 이미 고평가 |
| DC 인프라 (철강·전력·SK그룹 계열) | 국내 데이터센터 실물 착공 | SK그룹 DC는 공시 실측 전 서사 단계 |

## 6. 출구 계획 — 이 시나리오의 존재 이유

**전제: A는 "마지막 상승" 시나리오다.** ATH 재돌파 후는 사이클 종료 구간이며, 촉매는 후행적(고점 -30% 후 등장)이므로 **촉매를 기다리면 늦는다. 출구는 신호가 아니라 규칙으로.**

- **구조적 출구 신호 (하나라도 실측 시 분할 매도 개시)**:
  1. **증가율 정점 컨콜** — 엔비디아 2024 패턴: 사상 최대 실적 + 증가율 정점 조합의 콜 (P게임 ① 기계 적용)
  2. 2027 EPS 컨센 하향 리비전 개시
  3. 빅테크 CAPEX 가이던스 첫 하향 (무효화 §5-4와 동일 — 이 시점엔 롱 청산 신호로 기능)
  4. **HBM 캐파의 범용 역전환 실측** (존버맨 트리거④ — 공급과잉 폭탄의 장전)
  5. 호실적+하락 재출현 2연속 (배수 압축 재개)
- **기계적 규칙 (심리 방어)**: ATH 돌파 후 신규 매수 전면 금지 + 분할 매도 사다리 사전 설정 + "본전 심리·손실 보전 버티기 = 산화 경로"(김두한·Livermore 공통 경고) — admi_alts 규칙 적용: 매도 판정은 **매수 근거 훼손 or 지수 이상** 두 가지로만
- 시한 인식: 구조적 하락장 촉매들은 **2027년 수렴** 컨센 (김두한·존버맨 OP 피크 2027 일치) — 2차 상승의 소비 기한을 2026년 내로 보수 설정

## 8. 요약 — 한 장짜리

```
Phase 0 (7/29~30)  필수 2(하이닉스 P·Q + 빅테크 CAPEX) 통과 + FOMC 인상 없음. 배수는 D+2 종가로만 판정
Phase 1 (8월)      첫 반등은 무시, 되밀림 저점 유지 + 3Q 고정가 확인
Phase 2 (8말~9월)  HBM 2027 계약·EPS 상향·스퀴즈 개시 → 분할 진입 (170만 안착 1차·200만 안착 2차)
Phase 3 (4Q)       2차 상승·ATH 재도전 — 동반 랠리 폭 감시, 분기 채점 반복
출구               ATH 후 신규 금지·분할 매도 사다리 — 촉매 기다리지 말 것 (후행성)
분기               저점 붕괴→B / CDS·조달 붕괴→C / CAPEX 하향→C
```

- 은어 요약: 지금은 **벗지도 입지도 않는다** → Phase 2 확인 후 **스멀스멀 벗기** → ATH 후엔 **계획대로 입기** — 이번엔 진짜로.
