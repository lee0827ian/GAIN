> 성격: 프레임워크 v0.21 기반 모의판독·공부용 운용 규칙. 실제 주문 판단은 IAN.

## 0. 전제 — 뷰 요약 (양쪽 병기)

**구조(방향) = 롱 편향 유지**
- AI CAPEX 구조론 3층 소스 완성: 이론(AI-재정 결합) + 연준(워시 "기존 설비 전용 가능") + 재무부(베선트 "절대 져선 안 되는 경쟁") [07-22]
- HBM 대중 수출 봉쇄 유효 + 컴퓨트 병목("밀수·해외 DC로라도 엔비디아") — 수요의 하방은 정치적으로 방어됨 [07-23~24]
- 정책 수급: ADR 상장대금 외평기금 매입 검토 — 물량 소화 지원 [07-16]

**국면(타이밍) = P 게임 막바지 의심**
- P(가격)는 살아있음: MU +3.2%(7/23 미장) — 매크로 충격에도 메모리 P는 샀다
- 그러나 2차미분 둔화 + 배수 압축 신호(v0.20 P게임 9연작) — 호실적에도 하락하는 장(제씨 ⑥ 표본 3호까지 축적)
- **Q(물량) 전환 확인이 사이클 연장의 관건** (v0.19 퓨처워커 P/Q 렌즈)

**역풍(매크로)**
- 한은 인상 사이클(분기 +25bp) × 국장 레버리지 수급 = 청산 사이클의 상시 연료 [07-16]
- 유가발 인상 서사 부활(7월 확률 10%→35%) + 30Y 5% 고착 [07-23]
- 노무라 8월 경로: 실적 시즌 종료 후 변동성 쇼트 청산 리스크 — 국장은 7/24에 선행 집행(-5.72%)

## 1. 7/29(화) 실적 — 3축 채점표 (v0.20 확정 축)

| 축 | 확인 지표 | 상방 판정 | 하방 판정 |
|---|---|---|---|
| **P** | HBM·DRAM ASP 방향 + 3Q 가이던스 | ASP 상승 지속 + 가이던스 상향 | ASP 상승률 둔화 명시(2차미분 꺾임) |
| **Q** | 빗그로스·출하 가이던스, CAPEX 집행 | Q 성장 전환 명시(캐파 증설 → 출하 확대) | "P 위주, 출하 보수적" 유지 |
| **배수** | 실적 내용 대비 주가 반응 — **판정 시점·기준선 고정(v1.1)**: 발표 후 **2거래일(7/30·7/31) 종가** vs **7/28 종가(잠정 1,571,000 — 14:56 실측. 마감 확정치 확인 후 이 값 교체)** | 호실적(P·Q 통과) + D+2 종가가 기준선 위 = 배수 유지 | 호실적 + D+2 종가가 기준선 이하 = **배수 압축 확정**(제씨 ⑥ 표본 5호) — 판정 유예 불가 |

**배수 축 기계화 보칙 (v1.1, 07-28 레포 감사 반영)**: 기존 유보 3개(전일 -13% 선반영·ADR 전환 수급·데드캣 가능성)가 중첩되면 어떤 반응에도 판정 유예가 가능해 7칙 위반. 다음으로 고정한다 — ① 판정 변수는 **D+2 종가 단 하나**(장중가·당일 반응 사용 금지) ② ADR 전환 수급은 판정 변수가 아니라 **기관·기타법인 순매수 항목으로 분리 기록만** ③ 김석환 2단계(첫 반등 후 되밀림의 저점 유지)는 배수 축이 아니라 **8월 진행 조건(시나리오 A Phase 1)으로 이관** — 채점표와 국면 판독을 섞지 않는다. 기준선은 7/28 마감 후 확정치로 이 문단에서 갱신한다.

**조합 → 액션 (기계 판정)**

| 조합 | 판독 | 액션 |
|---|---|---|
| P↑ Q↑ 배수 유지 | 사이클 연장 확인 | **벗는(매수) 개시 구간** — 단 §3 게이트 통과 시에만 |
| P↑ Q? 배수 압축 | P 막바지 경계 강화 | 신규 진입 보류, 보유분 유지 |
| P↑ Q↑ 배수 압축 | 펀더 좋은데 시장이 안 사줌 | 보류 + 2주 관찰(배수 압축이 일시적인지) |
| P 둔화 명시 | P 게임 종료 신호 | 신규 금지, **입는(매도) 조건 §5 점검 개시** |

## 2. 가격 규칙 (레벨 기계화)

- **200만 = 매물대 상단·심리 문턱.** 4번째 도전 자체는 신호 아님 — **돌파 후 2거래일 안착**만 돌파로 인정 (7/22~24 3차 실패로 매물대 확인됨)
- **실적 전(7/25~28) 신규 진입 금지** — 채점 전 베팅은 판독이 아니라 도박
- 7/24 -8.3%는 유가·금리발 매크로 하락 — 종목 악재 아님. 단 **"낙폭 = 매수 근거" 금지.** 근거는 채점표가 만든다
- 진입 시 분할 원칙: 채점 통과 후 1/3 → 200만 안착 확인 후 1/3 → 나머지는 8월 창(§4) 통과 후

## 3. 매크로 게이트 — 신호등 실측 연동

**아래 중 🔴 2개 이상이면 채점이 좋아도 신규 진입 금지** (보유분 액션과는 별개)

| 게이트 | 기준 (v1.1 개정) | 현재 (7/28 실측) |
|---|---|---|
| WTI | 80 위 = 🔴 (트리거①) | 🔴 ~88 (방향은 하락 전환 — 공습 중단) |
| 이 년 | **방향+수요 조합(v1.1)**: 연중 고점(4.34) 경신 중 = 🔴 / 고점 하회 유지 + 입찰 수요 견조(응찰률 6회 평균 상회·테일 ≤0) = 🟡 / 고점 대비 -15bp 이상 + 수요 견조 = 🟢 | 🟡 4.31%(고점 4.34 하회) + 2Y 입찰 2.66배·테일 -0.5bp |
| VIX | 20 위 = 🔴 | 🟢 18.67 |
| 한은 | 10월 인상 단행 or 가속(+50bp급) = 🔴 | 🟡 경로 진행 중 |

→ **현 시점 게이트(7/28 개정 후): 🔴 1개 = 규칙상 잠금 아님. 단 §2 실적 전 진입 금지가 7/28까지 우선 적용** — 실질 효력은 7/29 채점 후부터.

**금리 게이트 개정 사유 (v1.1, 07-28 레포 감사 반영)**: 구기준 "기준금리 +0.5%p 이상 = 🔴"는 인상 프라이싱이 살아있는 한 상시 🔴인 레벨 게이트라, 기간 프리미엄 체제(유가 하락에도 금리 요지부동, 07-28 실측)에서는 **영구 잠김 = 관망 정당화 기계**가 된다. 레벨 대신 **방향(연중 고점 대비)과 수요(입찰 응찰률·테일)**로 판정한다 — 7/27 입찰 2.66배·테일 -0.5bp 같은 완화 재료가 반영될 경로 확보. WTI 게이트의 "74 복귀 = 해제"도 단독으로는 불충분(금리 게이트가 독립적으로 판정) — 두 게이트는 연동하지 않는다.

## 4. 노무라 8월 창 (계절 규칙)

- 8월 = 실적 시즌 종료 + 휴가철 유동성 감소 + 변동성 쇼트 재축적 → 청산 리스크 창
- 8월 중 신규 진입은 **계획 수량의 반액 상한**
- 단 **VIX 25+ 급등 시 = 패턴③ "청산은 기회"** 발동 검토 — 구조(§0 롱 편향)가 유효하다는 전제 하에, 채점 통과 종목 한정. 국장이 7/24에 경로를 선행 집행했으므로 미장 8월 재현 여부가 관전점

## 5. 무효화 조건 (뷰 폐기 = 입는 조건)

하나라도 실측 확인되면 롱 편향 자체를 재심사:

1. **중국 HBM 자립 실증** — 어센드에 국산 HBM 실탑재 확인 등 (현재는 격차 실측이 우세: 컴퓨팅 14%·EUV 자립 10~50년)
2. **Q 전환 실패 + P 꺾임 동시 확인** — P 게임 종료인데 Q가 못 받는 조합
3. **한은 가속(+50bp급 or 연속 인상)** — 레버리지 청산 사이클 본격 점화
4. AI CAPEX 정치적 방어 붕괴 — 빅테크 CAPEX 가이던스 일제 하향 같은 구조론 훼손
